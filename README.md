# herbrand-orchestrator 🚀

**Умный декларативный DevOps-Оптимизатор (Мозг над Terraform/Kubernetes)**

Система интеллектуального планирования, валидации и деплоя ИТ-инфраструктуры, построенная на базе логического программирования (Prolog) и теории графов.

## 🧠 Математический и Теоретико-Информационный Фундамент

Проект представляет собой совокупность алгебраических структур и двух связанных автоматов с магазинной памятью (Pushdown Automata), оперирующих в **Универсуме Эрбрана ($H$)**:

1. **Модель Данных**: Взвешенный ориентированный многокритериальный граф инфраструктуры $G = (V, E, W)$. Вершины — хосты/сервисы, ребра — сетевые связи и топологические зависимости.
2. **Компонент M1 (Парсер)**: Детерминированный автомат с магазинной памятью (DPDA), реализованный через исчисление контекстно-свободных грамматик детерминированных префиксов (DCG). На вход принимает пользовательский DSL-манифест, на выходе генерирует плоский граф отношений (фактов) в Универсуме Эрбрана.
3. **Компонент M2 (Оптимизатор/Солвер)**: Рекурсивный автомат-вычислитель, использующий механизм бэктрекинга WAM (Warren Abstract Machine) и логику ограничений `CLP(FD)`. Вычисляет оптимальную матрицу размещения (placement) сервисов с учетом ограничений (бюджет, RAM/CPU, связность).

## 📂 Структура проекта
* `src/` — Исходный код на SWI-Prolog.
* `docs/adr/` — Журнал архитектурных решений (Architecture Decision Records).
* `tests/` — Пошаговые тесты автоматов M1 и M2.
